# 路线图

## 当前（V0.2 桌面原型）

- 双图导入（参考图 + 原片）。
- 色彩管理（ICC → sRGB 统一分析空间）。
- 客观双图分析（直方图、明暗、色度、主色、色差）。
- 对应区域分析（矩形区域）。
- 可解释的调色指导（Photoshop / Camera Raw 操作步骤）。
- 三种学习模式（引导 / 练习 / 独立）。
- 仿色复盘与学习历史。
- 完全离线。

## 未来设想（不在本轮范围）

- **摄影师风格研究库**：按摄影师/风格整理参考图。
- **预设系统**：保存与分享仿色预设。
- **拍摄前指导**：根据目标风格给出拍摄参数建议。
- **AI 可选增强**：离线规则引擎之外，可选接入本地/云端模型做语义分析；AI 不作为架构依赖。
- **完整 RAW 显影器**：更完整的 RAW 处理流程。
- **Photoshop 自动操控**：直接驱动 Photoshop 执行调整（需要明确授权与安全边界）。

## 原则

当前任务只做仿色学习闭环，不提前开发上述未来功能。
