# 关键决策记录

## 2026-10-13：V0.1 采用 Python + Streamlit

- **考虑过**：纯 CLI、Web 服务、Streamlit 本地应用。
- **选择**：Streamlit 本地网页应用。
- **原因**：开发速度快，能快速验证“上传照片 → AI 分析 → 调色建议”的闭环；界面不用自己写。
- **代价**：交互能力有限，长任务（模型调用）会阻塞页面；模块重载机制导致改代码后必须重启服务。

## 2026-10-13：视觉模型选择云知声 MaaS

- **考虑过**：OpenAI 官方、国内多家大模型服务。
- **选择**：云知声 MaaS（U2 Flash）。
- **原因**：用户持有云知声 Key；OpenAI 兼容接口接入成本低。
- **代价**：U2 Flash 响应慢（一次请求 20-75 秒甚至更久），需要 300 秒超时和较大的 max_tokens；`response_format` 兼容性不确定，最终关闭了 JSON 模式。

## 2026-10-13：结构化输出使用 Pydantic

- **选择**：Pydantic 作为模型输出最终校验层。
- **原因**：字段强类型、可校验、失败时报错明确，防止模型返回非法结构。
- **代价**：需要额外的 JSON 解析和一次“格式修复”逻辑。

## 2026-10-13：历史记录使用 SQLite

- **选择**：SQLite，数据保存在项目 `data/` 目录。
- **原因**：零配置、单文件、足够本地使用。
- **代价**：多用户/并发场景不适用，但本地工具不需要。

## 2026-10-14：产品定位从 AI 修图转向离线仿色学习

- **背景**：市面已有成熟修图软件；AI API 有成本；参考图反推类产品已有。
- **选择**：聚焦“摄影参考图仿色分析与学习”，做离线桌面软件。
- **原因**：帮助用户理解颜色、学会仿色，而不是依赖自动修图。
- **代价**：放弃已经写好的 Streamlit/AI 调用部分，需要重构；旧代码保留在 Git 历史与文档中。

## 2026-10-14：桌面框架选择 PySide6

- **考虑过**：PySide6/PyQt6、PyWebview、Electron、Tauri。
- **选择**：PySide6。
- **原因**：纯 Python、原生控件、与现有分析模块无缝集成；打包简单。
- **代价**：界面观感比现代 Web UI 传统，需要自己写交互。

## 2026-10-14：色彩管理选择 Pillow ImageCms + Colour Science

- **选择**：Pillow `ImageCms` 读取/转换 ICC 配置文件；`colour-science` 做 Lab/OKLab 与色差计算。
- **原因**：成熟、维护良好、许可证宽松。
- **代价**：需要统一分析空间（sRGB）并明确记录“缺失配置文件时按 sRGB 假设”。

## 2026-10-14：调色指导采用可解释的规则引擎

- **选择**：用可测试的结构化规则生成指导，不依赖大模型。
- **原因**：本轮要求完全离线；规则可解释、可测试、无 API 费用。
- **代价**：规则的覆盖面有限，复杂场景需要不断补充规则。

## 2026-10-14：打包选择 PyInstaller

- **选择**：PyInstaller 生成 Windows 可执行文件。
- **原因**：社区成熟，支持 PySide6。
- **代价**：打包体积较大；杀毒软件可能误报。

## 本轮：有界预览与解释边界

采用最长边1600的分析/显示预览，统计1024、Lab/区域512。代价是极小取样与细小高光需要真实素材再校准；收益是避免24MP原图级浮点数组。保留原图尺寸与坐标，不把缩图像素数冒充原图像素数。

全局比较从假定像素对应改为均值与分布；平均颜色ΔE不能评价艺术风格。指导中的差值统一为“原片−参考”，分开Y′/255、L*和EV。

## 本轮：异步工作台与安全恢复

Qt工作线程只计算数据，主线程交付控件状态。任务有版本与取消检查；不强杀原生解码。选择128MiB/24条LRU和两个并发worker，接受少量串行等待以防重复解码、无界增长。

保存练习沿用原SQLite表，目标与视图信息放入结构化practice字段，旧记录仍可读取。草稿使用同目录临时文件、flush/fsync与原子替换。成功切换练习前才保存独立previous快照；失败、取消和期间新输入不能替换当前工作台。

## 本轮：预览版发布

选择0.3.0-preview而非稳定版标签，因为还没有真实ARW、广色域复杂ICC、多屏DPI与长时间摄影实践验证。PyInstaller目录包保留Qt动态库、原创图标和依赖许可证，不将用户数据或测试素材推到仓库。无新增云端调用。
