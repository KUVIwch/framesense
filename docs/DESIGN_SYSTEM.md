# FrameSense · Color Lab — 视觉系统

## 2026-10-15：从分析原型到摄影工作台

这轮设计用暗房工作台和摄影画册作为参照：照片占据主要面积，文字沿边缘组织，使用稳定的排版和细分隔线。没有渐变、发光、大面积装饰色，也不让每条分析结论都变成一张圆角卡片。设计的目的，是让人持续观察照片，而不是持续寻找按钮。

这是一套原创几何品牌资产和 Qt 原生组件样式。没有下载图标库、生成式图像或字体文件。图标设计与照片分析算法相互独立。

## 图标：三个实际方案

全部原始 SVG 保存在 `framesense/assets/concepts/`，可通过 `tools/generate_brand.py` 重建。每种方案都在深色、浅色底上检查了实际 16、32、64、256 像素的表现。检查图为 `outputs/product-preview/icon-study.png`，并非把小图放大后冒充小尺寸验证。

| 方案 | 结构 | 观察与取舍 |
| --- | --- | --- |
| 01 色彩取景（采用） | 四个开放取景角、三条错位的色彩切片 | 取景框表达观察边界，切片表达色彩比较；开放角保留呼吸感。16 像素仍能辨认框与内部的颜色节奏；64 像素以上能够读出切片的错位。 |
| 02 接触印样 | 双窗口、两块平面色、中央留白 | 比较的含义明确，但小尺寸更像通用窗口或排版按钮，品牌区分度较弱。保留为探索稿。 |
| 03 观察焦点 | 四分圆、偏移的中心留白 | 形状紧凑，小尺寸清楚；但圆盘结构更容易让人联想到通用统计图，与摄影观察的联系较弱。保留为探索稿。 |

正式方案没有普通相机轮廓、字母缩写或细小镜头孔。中心的三条切片就是被观察的焦点，不再额外叠加靶心。取景角使用相对粗的笔画，让小尺寸首先呈现轮廓而不是碎线。任务栏图标使用深色独立底板，在浅色桌面上也能保持边界；浅底品牌变体将结构改为深墨色。

### 已提供的资源

- `framesense.svg`：正式图标；`framesense-light.svg`：浅底变体。
- `framesense-16.png`、`framesense-32.png`、`framesense-64.png`、`framesense-256.png`、`framesense-512.png`：透明边缘的应用图标导出。
- `framesense.ico`：16、24、32、48、64、128、256 像素七个 Windows 帧。
- `brand-dark.svg`、`brand-light.svg`：应用内横向标识，包含 FrameSense 与 COLOR LAB。
- `readme-wordmark-dark.svg`、`readme-wordmark-light.svg`：README 的深浅配套标识，可用 HTML `picture` 的 `prefers-color-scheme` 切换。
- `check.svg`、`check-light.svg`：原创基础勾选符号，用于明确表达复选框状态。
- `chevron.svg`、`chevron-light.svg`：下拉选择器的方向提示，避免只留下文字输入框外观。

PNG、ICO 由相同 SVG 经 QtSvg 和 Pillow 导出；不依赖外部图形软件。ICO 除 256 像素外的帧由主图缩小产生。没有为 16 像素绘制另一套含义不同的标识，避免任务栏与应用内品牌割裂。

## 配色

颜色是工作界面的材料，不应成为照片色彩判断的依据。原图、预览图和统计值不得随主题变色。

| 用途 | 深色 | 浅色 |
| --- | --- | --- |
| 工作区底色 | `#151b1b` | `#eeebe4` |
| 工具与阅读表面 | `#1c2423` | `#f7f4ed` |
| 浮起状态 | `#252e2b` | `#e2ded4` |
| 图像工作底 | `#101514` | `#dedbd2` |
| 正文 | `#e6e0d5` | `#26342f` |
| 次要文字 | `#adb6ad` | `#59665e` |
| 细分隔线 | `#3c4943` | `#a8b0a5` |
| 主操作 / 铜色 | `#c78961` | `#8b4c2e` |
| 观察辅助 / 青绿 | `#6f9990` | `#3c7065` |

铜色用于当前主要动作和标签页的细下划线。青绿用于观察、选中状态和辅助提示，避免所有操作都争夺注意力。浅色主题的点缀色做了明度调整，不能直接把深色主题的铜色文字铺在米白底上。禁用状态保留可读轮廓，但不与可用操作等强。

`framesense/ui/theme.py` 的 `DARK`、`LIGHT` 是实际使用的唯一配色表。`apply_theme(app, name)` 同时更新 Qt 原生调色板、系统字体和样式表；`stylesheet(name)` 可用于局部预览。主题名只接受 `dark` / `light`，避免静默落入错误配色。

## 字体与排版

运行时优先选取系统的 Microsoft YaHei UI；其次 Segoe UI、Noto Sans CJK SC，最后交给系统无衬线回退。中文正文采用系统 10 pt，Qt 根据屏幕缩放处理物理像素。小标签可用 11 px，但不承载主要分析结论；区块标题 14 px / 半粗，品牌标题 21 px / 半粗。长分析采用正文层级，避免密集使用粗体和感叹号。

英文品牌使用 Segoe UI 系统回退，不把字体转成大批路径，也不随程序分发字体。Windows 的 Qt `offscreen` 后端在本环境不枚举系统字体；品牌导出脚本仅为无头截图读取本机 Windows Fonts 中的已有字体，不复制、安装或提交字体。真实 Windows 应用仍按系统字体机制运行。

## 间距与布局

间距使用 4 px 的倍数：4 为紧密关联，8 为图文间距，12 为组件内距，16 为区块留白，24 为大区隔。按钮最小高度由 20 px 内容加上下内距组成，常规约 36 px；图像工具按钮可更紧凑，但不依赖极小图标猜测功能。

工作区采用可拖动分隔条的参考图 / 自己的作品 / 分析侧栏。照片区域共享视觉基线；分析区使用标题、留白和页签组织信息。分隔条有足够宽度的命中区，悬停时出现明确反馈。小窗口优先保留照片和必要操作，详细说明放进可滚动阅读区。

## 组件约定

| 选择器 / 属性 | 用途 |
| --- | --- |
| `QLabel#brand` | 文字品牌；有横向 SVG 时优先使用品牌资源 |
| `QLabel#eyebrow` | 小型阶段提示，不用作大面积装饰标题 |
| `QLabel#sectionTitle` | 分析与图区的区块标题 |
| `QLabel#muted` / `role="subtle"` | 文件信息、操作提示等次要文字 |
| `QPushButton#primary` | 当前主要动作，同一局部只保留一个主要焦点 |
| `QPushButton#quiet` / `QToolButton#quiet` | 次要操作，悬停才显示背景 |
| `QFrame#toolbar` | 工具带，只有底部分隔线 |
| `QFrame#sidebar` | 阅读侧栏，只有侧边分隔线 |
| `QFrame#imageWell` | 照片承载区，不叠加卡片装饰 |

标签页使用文字和细下划线表达当前位置；输入框聚焦时有铜色边线；按钮聚焦有可见边界；复选框必须显示勾选符号，不能只靠颜色说明状态。菜单、下拉列表、工具提示、滚动条、进度条都使用同一套调色板。普通文本链接和选中文字仍有独立视觉反馈。

`asset_path()` 从包目录或 PyInstaller 的资源目录定位资产，不依赖工作目录。`brand_pixmap()` 直接将矢量图渲染为双倍像素并标记设备像素比；`app_icon()` 提供实际多尺寸 PNG。打包时必须携带 `framesense/assets` 目录。

## 文案与后续视觉检查

动作写成用户能执行的事，如“导入参考图”“查看差异”“导入调色结果”“保存练习”。提示解释现状与下一步，不用“赋能”“专业级智能”等宣传语。测量、经验建议、主观选择在内容层明确区分。

图标检查已覆盖深浅底和实际小尺寸。整体应用仍需结合真实照片、长文件名、中文路径、125% / 150% 系统缩放和窄窗口做人工检查；图标导出正确或自动测试通过，不等同于所有界面细节已经通过视觉验收。
