# 路线图

## 当前 0.3 预览

离线仿色学习闭环：参考与原片、分布和对应区域、规则指导、三个学习模式、导回结果与复盘、本地记录。加入统一视觉、原创图标、可取消后台工作、有界内容缓存、原子草稿和状态恢复。具体可验证证据见QA与PERFORMANCE，预览包不等同于稳定正式版。

## 下一阶段优先

1. 用实际摄影练习校准规则。先收集同一场景、不同场景和有意保留差异的案例，避免把构图差异当色偏。
2. 用真实Sony NEX-5N ARW与其他机型验证解码、白平衡/自动亮度显影假设及ICC转换。
3. 在100%、125%、150%、200%缩放和多屏环境真机检查布局、字体与拖动手感。
4. 按需读取高精度小区域，改善1600边长预览下极小区域的采样限制。
5. 更长时间的重复导入与会话测试，量化启动和PNG/RAW峰值；当前核心基准不能替代这些测量。

## 保留的远期设想

摄影师风格资料、预设、拍摄前观察提示、可选本地或云模型增强。AI不是核心依赖。完整RAW显影、Photoshop自动控制仍不在当前范围。
