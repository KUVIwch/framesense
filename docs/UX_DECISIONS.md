# 交互取舍

## 以照片为工作台中心

保留可调三栏，但给中间原片更多空间。顶部只保留练习标题、保存和记录；导入操作放回照片旁。观察、步骤、笔记和记录分开按需查看，避免首次打开就面对全部参数。窗口最小为900×620；1024×720下保留两张照片和主要操作，侧栏纵向滚动，Ctrl+B可收起。

采用深灰、暖白与少量铜色/青灰。浅色界面保留深色照片与直方图观察面，减少切换主题对视觉判断的干扰。系统字体不随软件分发。

## 查看和取样分开

默认左键拖动平移，滚轮以鼠标位置为锚点缩放；Shift拖动临时取样，R/V明确切换工具。对应区域仍由用户判断，不假设两张照片像素或内容相同。预览坐标映射回EXIF转向后的原图坐标。双画布按适合窗口的相对倍率和归一化中心联动，联动不是图像配准。

调后作品的取样框不冒充原片区域；切回原片恢复选择。原片和调后作品复盘属于同一次练习；更换原片或参考的文件内容后，下一次保存建立新记录，防止改写上一次练习。区域可清除与撤销，文字仍使用编辑框自己的撤销。

## 学习模式与结论

引导给完整解释；练习先显示观察，再由用户点开每一步操作；独立模式隐藏建议。三者共享照片、笔记和区域，不通过销毁页面来切换。全局均值、分布与对应区域只是不同证据；JPEG不能唯一反推作者参数。复盘写出实际测量变化，不以“更专业”或分数评价照片。

## 后台工作与恢复

加载、统计、比较和区域计算通过Qt工作线程完成。任务按通道替换；取消使用合作检查与结果丢弃，不强杀LibRaw或NumPy原生调用。两个并发工作线程限制过时任务积压，缓存用锁保护。线程只交付数据，主线程操作控件。

照片、模式与笔记有本机原子草稿。加载历史时先独立保存“切换前”工作台；取消、失败或期间继续输入/换图使过时恢复结果失效。整组照片成功打开后才切换。照片可能已被外部编辑，因此恢复不复用旧测量，而重新计算。失效路径由用户重新定位，旧数据保留到主动保存。

界面不反复弹确认框；错误留在状态栏，已有工作台内容保留。导入调后作品需要原片先就位，避免把旧调后图关联到新原片。
